# 背调工作站分工（推荐）

## 目标

- **Windows 客户端**：登录 `kevin`（或专用背调账号），只跑批量背调，窗口保持打开。
- **Mac（你本人）**：用管理员/其它账号做配置、搜索、开发信等日常操作。

两端账号不同，任务队列互不抢同一本地队列；云端共享已同步的配置与报告。

## 线上升级会不会打断 Windows 背调？

不会自动打断。桌面客户端打开后加载的是当时的网页脚本：

- 你在 Cursor 推送 GitHub → Vercel 部署新版后，**已打开的窗口不会自动刷新**
- 批量背调继续用旧页面逻辑跑完
- 只有手动「刷新页面」或关闭客户端才会停

新开的客户端/浏览器才会用到新版本。

## 安装包要不要每次重打？

**不用。** 账号密码与 API 配置以 **Supabase 云端** 为准：

1. 管理员在浏览器「保存配置」同步云端  
2. 任意电脑安装同一套客户端 → 登录已有账号即可  
3. 「导出桌面种子」仅作离线/空机兜底，配置变更后不必重打包

## Windows 注意

- 关闭系统睡眠 / 合盖休眠（否则队列会停）
- 可最小化窗口；客户端已关闭后台节流
- 退出客户端前会提示；退出后需重新打开并登录，未完成任务可自动续跑
