## 1. 设计初衷（一句话 + 展开）

### 1.1 一句话

让澄海玩具工厂与外贸团队，在 **同一个操作系统** 里完成「选品适市 → 设计出样 → 找对买家 → 背调匹配 → 开发触达 → CRM 跟进」，用 **可核对的证据**（货架/进口/背调画像）替代「靠感觉写邮件、靠人海查客户」。

### 1.2 为什么现在做

| 背景 | 含义 |
|------|------|
| 澄海是全球玩具产业带 | 工厂多、SKU 多、外向型强，但数字化工具碎片化 |
| 中小外贸团队贵、招人难 | 市调、美工、开发、跟单岗位重叠且不稳定 |
| 通用 AI / 通用外贸 SaaS | 不理解玩具包装、卖场、HS、平台卖家 vs 进口商 |
| 数据孤岛 | 海关、电商选品、CRM、设计工具各买一套，串不起来 |

### 1.3 产品哲学（写进 PPT 的三条原则）

1. **垂直先于通用**：玩具/礼品出口场景优先（包装形态、适市、渠道分型）。  
2. **证据先于文案**：商机与建议要能挂到「货架价带 / 进口行为 / 背调产品画像」。  
3. **任务流先于功能堆砌**：指挥舱引导小白按阶段推进，而不是 50 个菜单自学。

## 3. 行业痛点（会长与会员都懂的表述）

1. **找错客**：名单来自通用库，进口商/平台卖家/批发商分不清，开发信无效。  
2. **背调靠感觉**：没有包装、配色、价带、进口行为，匹配说不清。  
3. **设计与获客断裂**：美工出图与「卖给谁」无关；设计完才发现不适市。  
4. **工具拼盘贵**：海关数据、邮箱工具、生图、CRM、建站各买各的，不会用、数据不通。  
5. **人才断层**：会英语的不会玩具卖场；会开模的不会 Amazon 主图规范。  
6. **协会数字化抓手弱**：难向政府与会员展示「可量化的降本增效与产业升级」。

## 4. 平台功能地图（按板块，写给 PPT）

### 4.1 指挥舱
- 今日看板、澄海玩具出口任务流（选品 → 报价 → 设计 → 获客 → 背调 → 触达 → CRM）。

### 4.2 商机
- 客户搜索（库优先 + 联网）  
- 背景调查、产品分析、决策人挖掘、同类推荐  
- **产品匹配**（市调专家 + 产品经理 + 定价置信度 + 开发信组）  
- **背调补全**（品类/设计信号 + **结构化决策模型** 打渠道/适市/匹配分）  
- 规划中：海关情报、买家库、线上货架 × 线下进口「商机证据层」

### 4.3 产品
- 产品库、报价/选品单  
- 平面设计 Agent（电商主图/Listing/社媒/展会/多角度 Skills）  
- 包装设计 Agent（开窗盒、PDQ、盲盒、环保装等）  
- 3D 生成、AI 视频 Skills  
- 规划：3D 打印、认证/验厂/配件生态

### 4.4 宣发与联动
- 建站、社媒素材、联系工具（WhatsApp 等）、邮件营销、开发策略

### 4.5 差异化技术点（可对投资人讲一层）
- **任务流垂直**：澄海玩具出口剧本，不是通用 Chat。  
- **证据与决策分层**：对话模型做取证/生成；**决策模型**做渠道分型、适市打分、是否需补全（低延迟、可编程）。  
- **Skills 规格化**：设计/包装/视频/3D 内置行业工艺与负向约束，非空壳菜单。  
- **组织权限**：部门、额度、邮箱脱敏，适合协会会员「企业账号」推广。

## 7. 开发成本与估值（估算口径 · 供融资讨论）

> 以下为 **内部估算框架**，供会长与投资人理解「钱花在哪、值多少」；正式融资以财务审计与商务条款为准。  
> **重要**：150～250 万是 **「等价重建成本 / 市场重置价」** 估算，不是要求对方相信账面流水；PPT 中请写清「按同等交付物外包或市场化人力折算」。

### 7.0 开发成本估算依据（必须读 · 千问写进「成本页讲者备注」）

#### 7.0.1 估算方法（三法交叉，取交集）

| 方法 | 做法 | 本项目结论 |
|------|------|------------|
| **A. 等价人力法** | 模块范围 × 人月 × 市场化人月单价 | 约 **160～240 万**（见 7.0.3） |
| **B. 外包重置法** | 同类「多模块 B2B SaaS + AI 编排」外包报价区间 | 中小外包常 **120～300 万** 做不到同等垂直深度；本区间取中下 |
| **C. 功能点对照法** | 已落地业务模块数、代码量级、队列/权限/桌面端复杂度 | 支撑「不是 Demo，是可演示可试用 OS」→ 不宜低于 **150 万** 对外表述 |

三法交叉后对外统一口径：**约 150～250 万人民币等价开发投入**。

#### 7.0.2 范围依据（产品已建成什么 · 不是空喊）

基于当前仓库可核验的交付范围（融资口径用「范围事实」，不必念代码路径）：

| 范围事实 | 量级（约） | 对成本的含义 |
|----------|------------|--------------|
| 业务前端模块（Module 级） | **约 20+ 个**（商机/产品/设计/包装/3D/视频/CRM/邮件/建站/报价/市调匹配/背调/决策人等） | 多模块一体化，非单页工具 |
| 服务层与 API 编排文件 | **约 160+ 个** TS/TSX 业务文件量级 | 含队列、权限、组织、缓存、多模型代理 |
| 代码体量（业务源码合计） | **约 6 万行量级**（含前端+服务+接口，不含依赖） | 接近「小型成套 SaaS」而非原型 |
| 垂直能力包 | 平面/包装/视频/3D Skills、决策模型打分、背调补全队列、任务流 | AI 工程与行业工艺规格，外包溢价高 |
| 企业级能力 | 部门权限、额度、桌面端、管理后台、组织账号 | 比纯 C 端 Chat 贵一档 |

**结论**：按「能演示的产业垂直外贸 OS」计价，而不是按「一个 ChatGPT 套壳」计价。

| 云资源、Key、域名、小额第三方（现金） | — | 5～20 万 | 真实现金科目 |
| **合计** | **约 33～56 人月** | **约 153～252 万** | 与对外口径 **150～250 万** 对齐 |

> **讲者备注**：若对方问「你们实际账上花了多少？」——答：「早期团队自研压缩了现金支出；**对外谈的是重建这套系统在市场上要花的钱**，避免用过低账面成本压估值。」

#### 7.0.4 为什么不是 50 万、也不是 500 万

| 错误口径 | 为何不用 |
|----------|----------|
| 「几个人业余做的，最多 50 万」 | 忽略垂直 Skills、企业权限、多模块联调与可试用完整度；会 **低估资产、压估值** |
| 「对标大厂中台，至少 500～1000 万」 | 尚无全国级数据中台与大规模运维编制；会 **虚高、失信** |
| 本口径 150～250 万 | 对应「可演示的垂直外贸 OS + AI 工作流」，适合天使/产业共建讨论 |

#### 7.0.5 与估值的挂钩方式（避免乱喊倍数）

粗算逻辑（融资讨论用，非财务承诺）：

- 等价开发成本 **C ≈ 200 万（取中）**  
- 早期软件/产业数字化常见讨论：**重置成本 × 4～8 倍**（有场景与渠道溢价）→ 约 **800～1,600 万**（贴近保守～基准下沿）  
- 再叠加 **协会渠道 + 政府叙事 + 算力故事** 时，讨论上移到 **1,500～5,000 万**（见 7.3），依据是 **可转化会员与产业资源**，不是单纯代码倍数。

### 7.1 已投入 / 到位开发成本（估算汇总表）

| 科目 | 估算区间（人民币） | 依据摘要 |
|------|-------------------|----------|
| 产品研发（前后端、桌面端、队列、权限、多模块） | **80～150 万** | 约 18～36 人月 × 市场化单价；对应 20+ 业务模块 |
| AI 编排、垂直 Skills、决策模型接入、证据层占位 | **30～60 万** | 约 8～14 人月；含 Prompt/流程试错溢价 |
| 基础设施与第三方（云、域名、试用 Key 等） | **5～20 万** | 现金科目，可变 |
| 设计/品牌/文档/试点支持 | **10～25 万** | 产品方案 + UI + 试点材料 |
| **合计已投入量级（建议对外表述）** | **约 150～250 万** | 三法交叉；「已建成可演示可试用的产业垂直 OS」 |

### 7.2 未来 12～18 个月研发预算（若融资）

| 用途 | 建议预算 | 依据摘要 |
|------|----------|----------|
| 海关 + 线上货架证据层接通 | 40～80 万 | 数据对接 + 清洗展示 + 合规；偏集成与采购 |
| 协会会员体系、多租户计费、培训后台 | 30～50 万 | 约 6～12 人月产品化 |
| 生产/认证/物流生态对接 | 20～40 万 | 接口与生态占位落地 |
| 销售与成功案例（澄海试点） | 30～60 万 | 非纯研发：培训、实施、案例制作 |
| **小计** | **约 120～230 万** | 与「再融一轮把澄海做成标杆」匹配 |

### 7.3 估值讨论区间（天使 / 产业轮叙事）

在「澄海玩具协会可共建、可导入会员与政府资源」前提下，可用三档讨论（**非承诺**）：

| 情景 | 估值讨论区间 | 依据叙事 |
|------|--------------|----------|
| 保守 | **800～1,200 万** | 重置成本 × 约 4～6 + 早期产品可用；尚弱付费规模 |
| 基准（协会深度共建） | **1,500～2,500 万** | 协会样板 + 明确会员转化路径 + 政府数字化叙事 |
| 乐观（产业+算力故事） | **3,000～5,000 万** | 会员规模化 + 数据飞轮启动 + 算力出海试点立项 |

**融资用途建议表述**：产品完善（证据层）40% / 澄海标杆与培训 30% / 团队与运维 20% / 储备 10%。

**对会长友好的说法**：  
「不是要协会出钱赌技术，而是用协会信用换产业样板；产品已可试用，**市场上重建这套系统大约要一两百万**，融资用于把澄海做成全国玩具数字化外贸标杆，政绩与会员利益绑定。」

## 8. 说服协会会长：他为什么要参与

### 8.1 会长个人 / 协会「政绩」叙事

1. **会员看得见的降本**：统一培训、统一工具，年会可展示「N 家企业用上数字化外贸 OS」。  
2. **对上可报**：对接汕头「数字经济 / 外贸稳增长 / 产业集群」政策语汇。  
3. **对内可管**：会员企业账号、培训认证、优秀案例库，提升协会服务厚度。  
4. **风险可控**：先试点 20～50 家会员特惠，再规模化；协会可不承担技术债。

### 8.2 会长能拉来什么（PPT 单独一页）

| 资源 | 会长可发挥的作用 | 平台侧回报 |
|------|------------------|------------|
| 玩具行业大厂投资人 | 引荐产业投资、战略股东 | 资金 + 场景 + 标杆客户 |
| 汕头市政府相关部门 | 数字化试点、中小企业补贴、园区合作 | 资质与传播、可能的专项支持 |
| 协会会员网络 | 批量开通、行业会议演示 | ARR 与数据网络效应 |
| 展会 / 澄海展 | 联合展台、数字化专区 | 获客与品牌 |

### 8.3 给会长的「三句话电梯稿」

1. 「澄海不能只卖货，还要输出 **数字化外贸能力**；这套系统就是协会的新抓手。」  
2. 「会员少雇人、少买杂工具，协会有政绩，政府有产业数字化案例。」  
3. 「做成了，可以复用到潮玩、工艺礼品，再挂上汕头 **算力出海**，会长站在下一程的起点。」

## 9. 未来价值：从澄海玩具 → 算力出海 → 其它行业

### 9.1 三年叙事（建议路线图页）

| 阶段 | 时间 | 目标 |
|------|------|------|
| Year 1 | 澄海玩具会员深耕 | 协会样板、付费会员、证据层接通、标杆案例 |
| Year 2 | 汕头关联产业复制 | 礼品、工艺、美妆小件等「小件出口」同源能力 |
| Year 3 | 算力与平台输出 | 「汕头算力 + 产业 OS」打包服务其它产区 / 出海客户 |

### 9.2 算力出海（怎么讲才站得住）

- **近**：平台已 consum 大模型、生图、决策、视频等算力；会员充值即算力分发。  
- **中**：与汕头本地算力/云资源合作，协会与政府做「产业算力消费入口」。  
- **远**：把「垂直行业 OS + 本地算力」复制到其它地市产业集群（鞋服、五金、家具等），玩具验证方法论。

### 9.3 跨行业可复用模块

商机搜索/背调/CRM/匹配/设计 Agent/任务流 —— **换行业 Skills 与证据源** 即可复制；澄海是第一个「满分样板」。

## 10. 平台能为用户带来什么（利益清单 · PPT 金句）

1. **更快找对客**：渠道分型 + 适市打分，减少无效开发。  
2. **设计服务销售**：包装/主图按卖场 Skills 出，服务报价与匹配。  
3. **证据说话**：背调与补全写入画像，匹配与定价有置信度。  
4. **一人多岗**：助理级搜客+美工草稿+信函初稿，压缩编制。  
5. **资产沉淀**：客户库、产品库、设计资产留在企业，不随员工离职蒸发。  
6. **协会同盟**：培训、特惠、标杆，降低独自试错成本。
