# 外贸智慧协同 · 全平台演示操作提示词手册

> 用途：按模块逐步演示。每一节给出**入口、必选项、可直接粘贴的提示词/字段值、要点按钮、预期结果**。  
> 建议演示叙事：**澄海磁力片 / 泡泡枪 / 遥控车玩具 → 欧美进口商**。  
> 演示前请管理员确认：对话服务、生图服务、3D/视频服务（若要演示对应模块）已在后台就绪。

---

## 推荐演示总顺序（约 45–90 分钟）

| 序号 | 板块 | 模块 | 目的 |
|------|------|------|------|

## 1. 指挥舱 · 今日看板 + 任务流

### 1.1 顶栏

| 项 | 操作 |
|----|------|
| 选择/点击 | 「刷新」→ 看行业新闻、即时汇率是否更新 |
| 点击 | 「客户搜索」或「自动化获客」（可先不点，讲完任务流再进） |

### 1.2 任务流定盘（展开状态）

**「我有什么」三选一（演示建议）：**

- 选 **「我有工厂货源」**（澄海工厂叙事）

**目标市场（点选芯片）：**

- 选 **「欧盟 / 英国」** 或 **「北美」**

**目标市场输入框（可再改）：**

```text
德国 + 荷兰玩具进口商
```

**主推品类 / 关键词输入框：**

```text
magnetic tiles educational toys CE EN71
```

**剧本快捷（点一个即可）：**

- 「欧盟玩具批发」或「北美派对 / 电商」

**七步任务：**

- 可点第 1 步「去产品库」开始；或勾选完成圆点标记进度  
- 第 5 步「背调」需先有获客结果，演示时按序走

**预期：** 出现适市建议摘要；右侧七步列表可跳转模块。

## 2. 产品 · 产品库

| 项 | 内容 |
|----|------|
| 入口 | 球体导航 → **产品** → **产品库**；或任务流「去产品库」 |

### 2.1 适市 / 检索区（若有）

| 字段 | 填入 |
|------|------|
| 市场或国家 | `德国` |
| 品类关键词 | `磁力片、磁力积木` |

### 2.2 手工新增一条演示 SKU（推荐）

按页面「新增 / 录入」类按钮，填：

| 字段 | 填入 |
|------|------|
| 货号 | `DEMO-MT-139` |
| 品名 | `6.5CM 益智磁力片 139PCS` |
| 英文名 | `Magnetic Tiles Educational Set 139PCS` |
| 品类 | `磁力积木` |
| 规格备注 | `CE / EN71 · MOQ 500 · FOB Shantou` |
| 图片 | **本地上传 1～2 张清晰产品图**（避免失效外链） |

**Excel 已导入但无图：** 在右侧列表点该行左侧「图」格 → 选本机图片 → 即与该货号对应；悬停显示「上传 / 换图」。  
（也可在 Excel「图片」列嵌入图片后重新导入，系统会按货号合并。）

**搜索框可试：**

```text
DEMO-MT
```

**预期：** 列表出现该 SKU，带本机图片，可供设计/报价/发文调用。

|----|------|

| 选项 | 建议 |

```text
益智磁力片积木套装电商主图，白底棚拍，包装盒完整可见，色彩明亮儿童友好，适合亚马逊主图，高清，无水印无文字堆砌
```
